DLCO Pin-to-Pin Virtual Trainer Kit — prototype v2

Run:
1. Download and extract the ZIP.
2. Open index.html in Chrome or Edge.
3. Add input switch(es), add an IC, add output LED(s).
4. Click one pin/terminal, then click a second pin/terminal to make a wire.
5. Toggle input switches and watch output LED(s).
6. Click a wire and press Delete to remove it. Reset / Clear wires are available.

Actually simulated gate ICs:
- 7400 quad NAND
- 7404 hex inverter
- 7408 quad AND
- 7432 quad OR
- 7486 quad XOR
Pin names and DIP pin numbers are shown on the chip.
74151, 7476 and 7490 pin layouts are included as visual references but their full functional/timing models are not implemented in this prototype. The tool is not yet a complete electrical-level simulator. Gate logic defaults unconnected input nets to 0. Confirm physical pinouts with the lab manual before real connections.
